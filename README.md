# 🚗 GaadiMitra AI

GaadiMitra AI is an AI-powered car buying assistant designed for the Indian market 🇮🇳.  
It helps users find the best car based on their budget, preferences, and lifestyle.

---

## 🌐 Live Demo  
👉 https://gaadimitra-ai.netlify.app  

---

## ✨ Features  

- 🔍 Personalized car recommendations  
- 🚘 Covers 100+ cars from the Indian market  
- ⚡ Fast and interactive chatbot experience  
- 🎯 Smart matching based on user needs  
- ⚠️ Disclaimer system (AI suggestions should be verified)  
- 🔐 Basic security using domain restriction and rate limiting  

---

## 🧠 Key Learning  

- Handling AI model inconsistencies and hallucinations  
- Prompt engineering for better accuracy  
- Balancing response speed and quality  
- Debugging real-world issues during deployment  

---

## 🛠 Tech Stack  

- HTML, CSS, JavaScript  
- Flowise AI  
- OpenRouter API  
- Netlify (Deployment)
